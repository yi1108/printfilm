# 短剧视频提示词

提示词只描述当前镜头从已确认起点到终点的变化。不得改写剧情、替换台词、增加镜头或宣称任务已提交。

## 先确认输入

1. 保留原分镜的镜号、时长、人物、场景、动作、对白和结束状态，不用“更有电影感”为理由重写故事。
2. 区分提示词条目、真实参考素材和计划补图：只有当前项目实际提供并授权的媒体才能称为“已有参考”。
3. 素材 URL 只是地址，不代表已读取画面或声音。无法核实媒体内容时，只按用户声明的用途写约束，不描述未见过的人物或事件。
4. 用户没有提供参考图时，不写“保持参考图中的外貌”；改为在正文交代必要的静态视觉锚点。

## 参考职责

每项真实引用按“顺序｜素材｜用途｜控制｜不得控制”核对：

- 角色图负责身份和本场造型，不默认继承参考图背景、姿势或其他人物。
- 场景图负责地理、时段和光线，不替代本镜人物动作。
- 起始帧负责开场构图和可见状态，不把后续动作提前画入。
- 视频参考只继承用户点名的运镜、节奏、动作或风格，不默认继承人物身份和剧情。
- 音频参考只继承点名的音色、环境或音乐特征，不改写台词文本。

引用编号必须沿用请求实际提供的顺序；不得发明 `@Image 2`、`@Video 1` 等不存在的标签。优化已有提示词时必须保留原有 `@asset` 引用。

## 正文写法

1. 先写主体和可见起点，再写围绕叙事目标的连续动作链、镜头语言、光线氛围、必要声音和结束状态。
2. 动作遵循因果：先听见或接触，再产生反应；写清触发者、接触点、身体/物件响应和结果，不堆机械表情词。
3. 一个镜头以一种主导运镜为宜。运镜必须服从信息表达，并与人物移动和空间关系相容。
4. 对白逐字保留并绑定说话人。为倾听、呼吸、打断和反应留出时间；动作与台词放不下时优先减少动作，不擅自删台词。
5. 环境运动、道具状态和其他人物反应只写与本镜职责相关的内容。
6. 静态身份和场景事实可由真实参考承担；运动提示词负责镜头内变化，不重复堆砌相互矛盾的描述。
7. 不擅自添加字幕、水印、品牌、BGM 或额外对白。用户要求无声、无配乐或无字幕时明确写出。

## 模型与时长

- 有明确目标模型时只使用该模型已确认的参数和语法，不把其他模型的限制当成通用规则。
- 时长沿用分镜或用户指定值；时间区间应连续、无重叠且合计等于总时长。
- 不用空泛质量词代替可执行内容，不使用“保证完全一致”“绝不变化”等无法兑现的承诺。

## 单镜执行协议（GitHub 技能适配）

先在内部整理五项，再按画面、运镜、环境声、台词四行输出正文：参考职责、可见起点、主要动作链、唯一主导运镜、可见终点。不要输出分析表或把整段剧本复述进这一镜。

- 引用必须落在正文的角色或场景位置。请求给出 `@[名称](node:ID)` 标记时原样保留；不要改成自编的图片序号、网址或 Markdown 图片。编号由平台按实际上传顺序生成。
- 给参考明确职责：角色参考只锁定身份与本场造型；场景参考只锁定空间与光线。参考图不自动充当首帧或尾帧，不能照搬其中的背景人物、姿态或道具。
- 4–6 秒以一个主要动作及直接反应为写作目标，7–10 秒可写紧密相连的动作链，12–15 秒承载同场完整动作、对白与反应，可用内部时间段描述必要景别变化，不拆出新节点。先删掉旧提示词擅自增加的动作、修饰和重复，不擅自删除原分镜关键事件或改变起止状态；不把长距离进场、下马、跪地、举物、对白继续扩写成更长的表演。时长由实际节点决定，不在正文偷偷加长。
- 机位、运镜和主体运动分开描述。“固定镜头”不能同时“迅速推进”或“环绕”；固定机位若需景别变化，必须明确主体靠近或变焦，不把变焦与物理推进混为一谈。未指定时选择最能看清关键动作的一种简单运镜。
- 连续性检查必须具体到结束姿态、画面位置、朝向、手持物。上一镜的结束状态是本镜开场约束；本镜结尾为下一镜留出衔接，不把下一镜的事件搬进来。不要把未提供的前后镜当作已知事实。
- 最后去掉无依据的外貌、材质、伤痕、服装、光源和新人物；保留输入明确的事实。仅有图片地址时不宣称已看图。

六秒单镜例子（只示范写法，不替换当前剧情）：输入为“跪地传令兵举起竹简”，正文可为“人物身份与造型参考【角色标记】，营地空间与光线参考【场景标记】。中景，平视固定机位。传令兵已跪在画面中央，右手从胸前抬起竹简至肩高，身体随急促呼吸轻微起伏，结尾保持举简姿态。保留风声与呼吸声。”只有输入明确上述事实时才这样写；占位符必须换为请求中的真实标记。不要加写远处策马、冲营或跌落等新事件。

## 声画分离（必须执行）

当前镜头提示词按以下字段输出，声音区不要混入叙事散文：

画面：可见起点、主动作和终点，含真实角色、场景引用。
运镜：景别、机位和一种主导运动。
环境声：明确声源、强弱、持续或停止；嗓音和表演方式写在这里，不放入台词原文。
台词：说话人：“逐字原文”。无对白时明确写“台词：无”。多个说话人分别一行。

只有台词引号里的内容允许被说出口。所有画面、运镜、表演与环境声说明均为不朗读的导演指令。不要把“声音在风沙中撕裂”“他的语气充满悲凉”等文学描述串在对白后面；可执行的声音描述例如“嗓音嘶哑、台词断续、尾音被风声盖住”，仍然不得发声朗读。只采用当前分镜明确指定的对白，不从邻镜或全剧本补台词，不加旁白；若当前输入明确要求旁白，单独标为“旁白：说话人：“原文””。保留对白原语言。

语法参考火山方舟官方 Seedance 2.5 文档：https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh 。声音分层：音乐 `()`、音效 `<>`、台词 `{}`、字幕 `〖〗`。本应用先使用以上可读字段保存，再在提交阶段区分模型并标记台词；不要把特殊标记当作必须朗读的内容。

## 输出前检查

- 是否保留镜号、时长、台词、起止状态和全部真实引用？
- 是否说清每张参考的职责，且没有描述未读取的媒体内容？
- 是否围绕一个叙事目标形成连贯动作链，完整覆盖已规划对白和反应，且没有把长片段缩写成单个微动作？
- 是否没有自动提交生成、没有改变计费或模型参数、没有声称已经生成？
