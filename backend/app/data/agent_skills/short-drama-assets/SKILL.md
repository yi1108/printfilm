# 短剧视觉资产与连续性

把已确认剧本变成可复用的角色和场景资产。只规划，不生成图片，不提前拆分镜。

## 输入与边界

1. 必须先用 `read_canvas(node_ids=[剧本ID])` 读取完整剧本，不能只凭聊天摘要或节点标题猜内容。
2. 同时查看同一 `sourceScriptId` 的既有角色、场景和提示词；已有内容、媒体和用户修改必须保留。
3. 当前工具一次创建 `character` 或 `scene` 节点。道具不另造不支持的节点类型：把关键道具的身份、归属和状态写入相关角色或场景的 `description` 与 `prompt`。
4. 最终只调用一次 `plan_story_assets`，一次提交全部资产；不得调用生成工具，不得声称图片已经生成。

## 资产判断

- **身份**：换掉后不再是同一人物或地点，例如角色脸型、年龄段、时代、场景所在空间。
- **变体**：身份不变但服装、伤势、湿污、时段、天气或光线改变。写清生效范围，不重复创造新身份。
- **镜头瞬态**：姿势、视线、左右手、站位和相机角度留给分镜，不冻结成角色永久特征。
- **持续关系**：长期持物、身体依托、固定位置等会限制后续动作的关系，要写入状态和连续性依据。
- 含混指代、未决定外貌或无法确认的道具归属不得编造；在 `description` 标为“待确认”，其他可确定内容照常完成。

## 每项输出

每项必须包含：

- `kind`：只能是 `character` 或 `scene`。
- `name`：短而稳定的名称，不堆造型或剧情形容词。
- `description`：剧本依据、身份与变体、可见状态、关键道具及待确认项。
- `prompt`：只填写当前资产的具体视觉约束，包括主体、构图、风格与一致性。例如“现代小饭馆后厨，灶台与取餐窗相邻，白天自然光，空场景，无主要角色”。不能把“只写要求”“正文留空”“后续生成”等规划流程指令写进这个字段。

工具负责把 `prompt` 保存为写作要求并将写作节点正文初始化为空；不要让写作要求命令下一阶段继续留空或继续规划。运行写作节点时应直接产出最终图片提示词。

角色提示词依次写清：性别与年龄段、脸部识别锚点、发型、体态、当前服装和配饰、时代与画风、光线和构图。没有剧本依据的细节采用克制且可复用的视觉补充，不写复杂剧情动作。

场景提示词依次写清：地点与时代、空间结构、环境陈设、时段与天气、光线方向和色温、画风与构图。场景参考图默认空场景，无主要角色、无字幕、无水印；不能因剧本出现人物就把人物塞进场景板。

## 连续性锁

1. 对跨镜必须保持一致的外貌、服装、道具、地理和光线，提炼一条可原样复用的最小短语，写进对应 `description` 和 `prompt`。
2. 只锁不随剧情变化的事实。会变化的服装、伤势、道具状态写“状态 + 生效范围”，不要把所有场次锁成同一状态。
3. 角色与场景使用同一视觉媒介、时代和色彩体系；不得一个写实、另一个无依据地变成卡通。
4. 参考图提示词只描述应静止保存的视觉事实，不写“下一镜”“转身之后”等时间过程。

## 完成前检查

- 剧本中主要角色和必要场景是否完整覆盖，是否误加无关人物？
- 是否区分身份、变体和瞬态，是否保留已有资产？
- 每条提示词是否可见、可生成、可比较，而非空泛的“高级、唯美、电影感”？
- 关键道具的归属和状态是否明确，角色与场景是否属于同一剧本？
- 是否只返回工具调用，没有把资产清单当作最终交付？
