# 导演技能选择与工作流 · 2026-11-07

参考依据是用户提供的 Paba 截图与仓库已有的对照资料。公开搜索未找到可核验的 Paba 导演技能原文；新增技能为本项目自己的指令，不宣称复制其内部实现。

## 使用入口

- Agent 输入框上方“导演技能”：展开后选择阶段与技能，查看描述和完整规则；支持键盘方向键选择。
- 五个阶段：剧本创作、角色与场景、按场拆镜、镜头提示词、剪辑指导。
- 复用视觉资产、剧情分镜、通用视频提示词、Seedance 专用等现有技能；新增剧本导演、剪辑导演、产品广告导演、纪实访谈导演。
- 每阶段单选，可明确选择不使用；浏览器按项目保存选择，加载时过滤无权限、停用和阶段不匹配的旧选择。
- 常见明确意图可定位到对应阶段，故事引导按钮直接锁定资产或分镜阶段。

## 执行链路

1. 客户端发送当前阶段选择及各阶段配置；后端在创建计费运行前验证可见性、启用状态、阶段与单选数量。
2. 只注入当前阶段选中的技能。默认只选对应的一个内置技能，不叠加全部匹配项；助手模式不注入。
3. 分镜规划使用所选分镜技能，同时明确只创建写作要求和节点，正文留空，不越过规划阶段。
4. 新建角色/场景与分镜写作节点继承对应的写作技能 ID；重复规划保留用户在已有节点上的选择。
5. 文本节点可单独选择“导演写作技能”。流式写作和后台写作都加载同一套服务端技能；写作期间修改要求、技能或参考时，旧结果不覆盖新内容。
6. 导演模式服务端默认不开放收费媒体生成工具；显式工具设置、编辑权限、版本及计费规则继续生效。

## 单个文本节点运行

- 文本生成按钮始终只生成当前文本，引用素材读取现有结果，禁用画布与媒体工具。
- 单独对一个文本节点执行“运行到这里”时，后台报价带 `text_only=true`，计划只含目标文本，不遍历、生成上游节点；已有正文也可以重新写作。
- 视频、图片目标的依赖工作流继续按有效结果和依赖顺序执行。

## 检查与修复

- 移除原先分镜规划直接跳过 Skill 注入的逻辑。
- 单个文本不再隐式调用所有上游依赖。
- 旧普通视频关联空写作节点时保留已有提示词；故事分镜仍严格读取关联写作节点。
- 会话历史测试补齐计费任务表，避免测试准备阶段缺表。
