# 创作流程检查与修复 · 2026-11-07

范围：剧本场次解析、角色场景抽取、按场拆镜、提示词写作、依赖运行、媒体提交及剪辑处理。未调用收费的模型或生成接口，未进行人工浏览器验收。

修复：

- 后台依赖运行根据下游参数判断写作结果是否过期，模型、时长、比例变更后重新执行提示词写作。
- 图片发起视频时保留视频请求的模型与参数，不把源图片的模型参数用于视频生成。
- 角色、场景重生使用当前关联写作节点；兼容旧节点时优先使用当前节点提示词。
- 模型参数控件自动调整时同步保存节点，避免显示值、提示词绑定和实际请求参数不一致。
- 图片写作与视频写作类型分离，兼容旧的角色场景写作节点。
- 追加分镜延续已有场次和场内镜头编号；重复规划保持原引用，避免额外连入其他场景。
- 单镜拒绝多个场景或冲突的场景 ID；相同地点的新场次可以单独分组。
- 解析“场1”“第1场”等剧本标题；重复地点复用场景参考图，避免自动补齐时创建重复条目。
- 已停止的后台工作流不再继续提交下游任务。
- 后台写作完成时重新读取画布，正文、要求或素材变化则保留用户编辑并按失败退回文字预扣费用。

- 前端写作输入框、依赖规划、创作引导、故事板等：21 项通过。
- `npx tsc -b` 通过。
- 媒体处理回归使用本地合成测试素材，覆盖截取、变速、音视频分离、提帧等；不调用生成供应商。

限制：检查覆盖上述代码与自动化回归，并不代表已验证真实供应商的出图或视频质量。已有提示词需要重新生成才能应用新的写作规则。
