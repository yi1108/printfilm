# 故事板详情工作区

按本轮提供的七张 Paba 截图实现。保留全部素材概览，新增分类网格与详情布局；没有访问或修改 Paba 服务。

## 交互与数据

- 全部、音频、文本、图片、视频分类；数量、独立滚动、展开分类、添加素材、卡片选中状态。
- 单击卡片进入左侧列表与右侧详情；返回分类网格、在画布中定位、向助手提问。
- 详情操作支持重命名、复制、替换、下载、节点生成历史和删除；只读时禁止写入。
- 文本：内嵌 Markdown 富文本编辑器，标题、加粗、斜体、列表、分隔线、复制；自己写/AI 写切换，写作类型、模型、技能、参考素材和运行状态。复用原文本生成流程与内容冲突保护。
- 写作参考支持文本与图片节点、图片缩略图、增删连线；生成上下文传入参考描述/提示词/素材地址及节点 ID，不新增视觉识别模型。
- 图片：结果预览、编辑、裁剪、图生视频、参考生成视频、下载、多结果切换/对比/拆开；空节点直接使用现有图片生成表单。
- 视频：播放器、裁剪、提取音频、参考素材、提示词、模型、生成模式与参数。费用预估、生成和状态查询使用既有接口。
- 音频：配音输入、音色、费用预估、生成及播放、裁剪；音效/配乐为上传入口。现有后端没有独立音效/音乐生成能力，本次没有伪造对应模型请求。
- 提示词编辑即时写入同一节点；切换素材/视图和自动保存不丢草稿。分镜视频仍使用关联文本节点中的提示词。

## 分镜条

- 将就绪图片/视频加入序列，也可一次加入所有就绪素材。
- 前移、后移、移除、清空；清空序列不删除节点。
- 图片停留时长可编辑；视频采用节点现有时长。
- 顺序保存在节点 `storyboardOrder`，停留时间保存在 `storyboardDuration`，沿用画布保存和撤销/重做。
- 连续预览按顺序播放视频与图片，可前后切换、暂停、选择已上传音频作为预览背景音。
- 剪辑入口把两个以上就绪视频按序连接到合成节点，在生成表单确认后调用原合成接口。
- 背景音用于预览，不写入最终合成；图片可以连续预览，现有合成接口仅接视频。相关按钮按实际能力限制。
