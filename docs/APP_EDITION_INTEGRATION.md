# App 国内版／国际版投放联调

更新日期：2026-11-10。本次仅实现作者选择、存储、审核查看及App查询筛选。没有修改播放会话、支付、钱包、解锁、分享和互动接口。

## 作者发布与编辑

单视频和系列选择“平台投放收益”时，展示“App投放版本”，可勾选国内版、国际版或同时勾选。至少一项。系列所有分集继承，收费系列的免费集同样继承，不逐集配置。

以下原有接口新增 `app_editions` 字段，其余原必填字段及版本号规则不变：

- `POST /api/marketplace/works`
- `PUT /api/marketplace/works/{work_id}`
- `POST /api/marketplace/series`
- `PATCH /api/marketplace/series/{series_id}`

两版投放示例（单视频创建）：

```json
{
  "title":"示例作品",
  "price_fen":0,
  "sale_type":"platform_unlock",
  "unlock_price_fen":100,
  "app_editions":["domestic","international"]
}
```

国内版只传 `["domestic"]`，国际版只传 `["international"]`。空数组、未知值、null、非数组拒绝；重复项规范化。编辑不传字段则保留原值，旧客户端创建不传则默认国内版。保存修改沿用既有重审、下架和版本控制，不直接绕过审核。

作者详情和后台审核可读取该字段进行回显。漫剧导入默认国内版，在导入后的通用系列编辑页选择；往已有系列同步成片不重置其投放选择。切换中英文或收益方式不清除当前选择。

## App查询参数

仅内容流及其分类、关键词搜索使用 `app_edition=domestic|international`，省略默认国内版：

```http
GET /api/marketplace/app/v1/feed?app_edition=domestic&limit=20
```

- 国内版查询返回仅国内及两版投放内容；国际版返回仅国际及两版投放内容。
- 独立免费作品沿用两版可见，不受作者隐藏的投放设置影响；收费系列中的免费集跟随系列范围。
- 版权出售收益仍不进入App内容流；审核、上下架、版权、封禁、屏蔽作者及分类搜索等原规则继续生效。
- 范围筛选在SQL中先于排序和分页执行，只控制发现及搜索结果。单视频详情、系列详情和分集目录不按投放版本限制，继续执行审核、上下架、版权、封禁和屏蔽作者等原有规则。
- 无效参数（例如 `app_edition=all`）返回422。使用两版的作品设置不会让查询接受 `both` 或 `all`。
- 参数与 `Accept-Language` 相互独立，国际版可以请求中文标签，国内版也可以请求英文标签。
- feed游标绑定版本筛选，跨版本复用返回422 `MARKETPLACE_CURSOR_INVALID`。切换版本、筛选条件或排序时清空游标重新加载。旧时间游标只兼容国内版latest查询。
- App只需在feed及其搜索请求附加自身版本参数，不需要先拉取全部再过滤。详情和分集目录不声明此参数；兼容客户端继续携带多余参数，但不会据此筛选。

详情及目录请求示例：

```http
GET /api/marketplace/app/v1/works/101
GET /api/marketplace/app/v1/series/201
GET /api/marketplace/app/v1/series/201/episodes?limit=20
```

## 历史数据与发布

新增作品、系列的JSON列 `app_editions`，默认 `["domestic"]`。API启动沿用统一数据库锁幂等补列，重复启动不重置已保存的选择，不改作品版本、历史订单或财务数据。历史平台投放作品因此默认国内版，作者编辑选择国际版并按原流程审核后才能出现在国际版查询中。

本次只做查询分发，不是地域版权封锁，也不是跨版本播放鉴权改造。直接播放、新解锁及历史权益接口保持原语义；App应从对应版本的查询结果进入业务流程。

后台“数字资产平台运营”审核详情显示国内版／国际版设置，不新增支付渠道和钱包配置。两版App继续使用既有账号和钱包。

## 联调重点

- 国内、国际、两版的查询结果及分页正确，英语请求不改变版本筛选。
- 系列卡片按投放范围筛选，已知编号进入详情及分集目录不受版本限制；封禁及其他原有限制仍然生效。
- 作者保存后回显正确，旧客户端更新未传新字段不重置投放范围。
- 空选择不能保存；feed非法版本值返回422；另一版本的公开详情仍可正常读取。
- 历史作品默认国内版，重复启动迁移保留新设置；播放、解锁和财务回归保持原样。
