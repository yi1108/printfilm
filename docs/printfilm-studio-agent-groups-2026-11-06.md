# Agent 改动预览与故事分组验收

## 实现

- Agent 的画布写入先返回改动方案。卡片支持只应用、应用并运行、忽略、撤销；应用状态随画布保存，方案随会话事件恢复。
- 顶部固定三步计划：剧本、人物与场景参考、分镜。未处理方案时不能继续下一步。
- 人物、场景、分镜分别建立分组，组内每行是写作文本和对应图片/视频。分镜保留角色、场景参考连线，剧本独立。
- 批量运行读取当前写作文本，先选择模型并估算费用，再确认提交。跳过已完成/运行中的节点；参考图缺失、跨剧本关联、费用变化会阻止提交。
- 撤销不会覆盖后续编辑、已生成媒体或新增关联。画布可缩小到 8%，适配较大的故事分组。

## 验证

- 前端完整测试：237 passed；后端相关回归：93 passed。
- 后续针对写作文本、历史恢复及分组修改：后端 23 passed，前端生成/方案 7 passed、故事引导 7 passed。
- TypeScript/Vite 构建通过；保留既有大包和混合动态导入提示。
- 浏览器使用真实 AgentPanel、StoryGuide、ProposalCard、StudioNodeCard 和 BatchRunDialog 组件，在内存样例中验证：应用、撤销、重新应用、继续分镜、3/3 计划、三类分组、参考连线、模型默认值、费用明细和运行回调。
- 样例入口：`http://localhost:5173/tests/fixtures/agent-review.html`。模型、报价和运行使用样例数据，未提交付费任务。正式项目页面在验收浏览器需要登录，因此不将样例验证记为真实项目生成验收。
- 等当前 Agent 结束且任务队列空闲后重启本地 8000 后端。健康检查通过，运行实例的 OpenAPI 已包含 `StreamRequest.review_changes: boolean`，确认加载本次新流程。
