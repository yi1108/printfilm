## 修复

1. 全局任务列表仅在任务抽屉打开时读取，按当前项目过滤；节点任务状态改变时更新，没有常驻列表轮询。
2. 客户端收到 `done` 立即完成并取消读取，不等待 HTTP 连接关闭；完成后的额外内容不再交给写作回调。
3. 上游 SSE 返回 `finish_reason=stop` 即关闭读取，不等待缺失的 `[DONE]` 或远端断开。
4. 流式调用增加绝对超时，避免持续心跳无限延长请求。单文本与后台写作限时 180 秒，后台超时清理运行状态、按失败结算并退款。
5. 写作输入框显示等待秒数和已生成正文预览；超时返回明确原因。
6. 后端补充开始、首段正文、完成、超时日志，只记录模型、字数和耗时，不记录密钥或正文。
