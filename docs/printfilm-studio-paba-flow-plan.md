# Printfilm Studio Flow 工作台实施计划

## 目标

以 Paba Flow 的深色故事板和无限画布为交互参考，把 Printfilm Studio 做成一个可完成“剧本 → 参考图 → 视频任务 → 资产回写”的工作台。实现只复用 ai_movie 现有的认证、项目、资产、任务、模型、计费和团队权限，不保存外部站点账号信息。

## 交付批次

### 批次一：工作台壳层和双视图

- 顶部项目、集数、保存状态、模型、分享和账号工具栏。
- 画布 / 故事板切换。
- 深色网格画布、节点拖拽、连线、缩放、缩略图、吸附和资产库。
- 故事板按音频、文本、图片、视频分栏展示，并从同一份 Printfilm Studio JSON 读取。

验收：切换视图不丢节点；刷新后节点和视口一致；非法项目地址给出明确提示。

### 批次二：节点工作流

- 节点选中状态和删除。
- 图片节点操作条：编辑、裁剪、图生视频、参考生成视频、下载、预览。
- 参考图和资产拖入节点；生成参数写入节点数据。
- 任务状态在节点和故事板中同步。

验收：用户可以从资产库添加图片，选中图片后打开操作条，并把生成意图提交到 Agent 会话。

### 批次三：Agent 工作流

- 右侧可停靠 Agent 面板和底部浮动入口。
- 会话恢复、流式 NDJSON、思考、工具调用、画布 Patch、任务创建和错误事件轨迹。
- 停止、取消、断线后恢复当前会话。
- Agent 写入画布使用版本链路，不覆盖人工编辑。

验收：Agent 可以读取画布、规划镜头、产生结构化事件；停止后状态为已停止，刷新后会话仍可见。

### 批次四：媒体任务联动

- 图片、视频、音频任务统一使用现有任务调度器和计费入口。
- 余额不足、模型不可用、任务失败和重试均有可读状态。
- 完成的资产自动回写到节点和故事板。

验收：创建任务前完成价格和余额校验；任务完成后媒体预览可播放；失败任务保留重试入口。

### 批次五：权限、发布和回滚

- 个人和团队项目按真实归属隔离。
- 团队编辑锁失效后切只读，Agent 不能继续写画布。
- `PRINTFILM_STUDIO_ENABLED` 控制新入口和新 API。
- 关闭开关保留数据，不自动切回旧画布。

验收：个人、团队、无权限、锁过期和并发保存场景均有稳定响应码和前端提示。

## 验证方式

- 前端：TypeScript 构建、现有 Node 测试、画布编解码和 Agent 事件解析测试。
- 后端：Printfilm Studio 画布、工具、运行时、权限和版本冲突测试。
- 手工：使用真实项目 ID打开 `/drama/projects/:projectId/printfilm-studio`，分别验收故事板、画布、资产库、Agent 和保存恢复。

## 2026-11-04：浅色 Flow 验收与实现顺序

以用户本次截图为界面基准，独立目录、FastAPI、现有媒体任务、计费、权限和编辑锁仍是迁移边界。截图中的第三方品牌、外部交流群、公共素材目录不直接复制进 Printfilm 产品。外站账号不写入代码、日志或文档。

### 本轮已实现

1. 左下角素材管理入口和左侧白色素材面板；项目素材与我的素材切换；按名称、类型、标签筛选；浏览器本地收藏；素材缩略图与空态；点击置入画布中央或拖到指定坐标。
2. 新增项目素材导入和上传接口，复用既有项目资产表及 OSS。媒体先持久化，再绑定节点；导入其他可访问项目素材时复制到目标项目。图片 20MB、音频 30MB、视频 100MB；存储关闭返回明确错误。
3. 图片主区域单击选中/拖动，双击展开编辑浮层；关闭 Agent 后右下角保持入口；新建生成节点使用新节点 ID 打开编辑器。
4. 分组使用 React Flow 父子关系和相对坐标，支持整体移动、框尺寸调整、双击名称编辑、取消分组、带子节点复制和删除。编解码保留分组尺寸、父节点和端口字段。
5. 后端保存改用单条 SQL 的版本比较与递增；无效画布/越项目资产引用返回 422，旧版本保存返回 409。前端保留保存过程中新增的修改，并阻止 Agent 远端画布静默覆盖本地修改。
6. 新项目路由重新挂载独立状态；恢复会话时加载历史消息；Agent 会话每次访问重新校验项目权限；只读模式阻止画布修改。
7. 图片编辑传递真实参考文件；视频参数按资料自动选择文生视频、首尾帧或混合参考，上传索引和媒体角色对应。提交生成期间阻止重复提交。
8. 剪辑合成复用现有 MP4 拼接器，按连接素材顺序生成新成片并上传为项目资产；编码不兼容时明确报错。图片裁剪结果同样持久化到资产。
9. 故事板按实际媒体类型分类，视频/音频使用播放器，文本和媒体可打开节点检查器。

### 后续验收顺序与尚存差距

- 优先级一：登录本地项目，手工验证上传→素材筛选→拖入→双击编辑→生成→任务回写→刷新恢复，以及团队只读/锁失效与两个页面保存冲突。
- 优先级二：Agent 运行恢复仍需补完整的持久事件序号及断线重放；本轮只验证消息历史恢复，不把它视为流式事件恢复完成。
- 优先级三：配方菜单仍未形成可复用工作流；3D 导演台、精确蒙版局部编辑等高级节点尚未达到 Paba 对应能力，不将提示词预置计为完整实现。
- 公共素材需接入实际可授权的目录；当前提供项目素材与当前账号有权访问的我的素材，不用演示数据冒充公共目录。
- 浏览器操作在本机 Work 设置中被禁用，网页读取工具也未能打开 paba.tv。因此未登录外站、未进行浏览器 E2E、未提交付费模型任务。当前验收依据是用户截图、本地 Toonflow 源码、自动化测试、构建及本地 API 健康检查。

### 本轮验证

- 后端定向测试覆盖编解码、Patch、Agent、保存版本冲突、非法文档、素材导入权限与上传参数校验；全部在临时测试存储执行。
- 前端执行全部 Node 测试、静态检查及 TypeScript/Vite 构建；保留构建已有的大包告警。
- 本地前后端已启动；/api/health 正常，Printfilm Studio 功能开关开启，上传/导入接口已出现在 OpenAPI 中。
- 没有提交 Git、推送远端或发布生产。
