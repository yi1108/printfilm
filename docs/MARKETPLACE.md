## 当前实现规范：作品广场（单视频与短剧）+ 平台投放（2026-10-26）

本节是当前产品和接口的准则，优先于本文后面的历史记录。市场保留原有单视频作品，新增独立的短剧系列与分集模型；历史作品不会自动迁移。单视频和每个分集都使用不可变发布版本，修改视频、权属材料、收费类型或价格后必须重新提交审核。作品内容与版权信息在同一次管理员审核中完成，不要求用户先做“版权审核”再做“内容审核”。

收费类型只有三种：

- `free`：审核通过并上架后通过短时签名播放完整原片，不生成试看或烧录水印。免费不代表可以任意商用，也不承诺防录屏。
- `copyright_contact`：只展示最多 15 秒且不超过原片 30% 的独立无水印短试看；参考价为 0 也不会自动变成免费。购买版权通过真实客服线下协商。
- `platform_unlock`：单视频或单集单独配置解锁价；未购买看试看，支付成功后永久在线播放，不返回原片地址。

平台投放作品必须先由后台配置默认创作者分成比例；作品或分集可以覆盖该比例。没有默认比例时只能保存草稿，提交审核返回 `MARKETPLACE_REVENUE_CONFIG_REQUIRED`。订单、永久权益、收益账本和人工打款使用独立 `marketplace_` 表，不复用原 AI 钱包或订单，不提供退款和自动提现。支付配置缺失返回 `MARKETPLACE_PAYMENT_UNAVAILABLE`。

短剧和单视频一起出现在作品广场。作者可以删除自己的作品，删除是软删：记录、文件和审核历史保留，作品从我的作品和作品广场撤下，不能再上架。发布入口有「发布作品」，也可以从 PrintFilm 成片页进入「发布到数字资产市场」。科普成片和明确选中的漫剧分集只提交编号，由市场 Worker 复制到 `marketplace/`；同一成片版本重复点击不会生成第二份草稿，原项目重新生成后用新版本再发布。草稿可以先保存，提交审核前仍要签署账号授权函，管理员一次审核内容和版权，通过后由作者上架。

版权材料按来源简化：PrintFilm 生成只需关联当前有效的签署授权函；其他平台需要证书编号、证书截图/照片和“版权纠纷与平台无关”确认；没有材料时只能联系客服协办，不创建新的登记案件，也不会自动通过。客服购买版权和招募接单均使用后台维护的真实二维码，不使用虚假或社区微信。

同一个市场 Worker 负责成片复制、上传后媒体校验、收费短试看和平台 HLS 播放版本，数据库持久化任务、租约和重试，随 API 自动启动并由看门狗恢复；不修改原项目 Worker、AI 调度、计费、漫剧表或存储目录。免费系列全部分集和收费系列前 N 个免费集直接播放原片；其余分集使用独立短试看。平台投放收费内容审核通过后生成同源分辨率 HLS。共用 OSS 但固定使用 `marketplace/` 前缀，OSS 未配置时上传和依赖媒体的接口返回 503 `MARKETPLACE_STORAGE_UNAVAILABLE`，不回退本地文件。

### 无水印短试看与历史任务升级

- 免费内容 `preview_status=none` 表示无需试看，资料齐备直接进入 `pending`。上传和保存草稿不生成试看。
- 收费内容提交后进入 `processing`，生成独立短片后再进入 `pending`。优先无损裁剪封装；不满足浏览器编码要求或实际时长上限时，只对短片段作同源分辨率高质量编码。输出经 FFprobe 验证后才上传，不改动原片。
- 新对象目录为 `marketplace/previews-v2/works/` 和 `marketplace/previews-v2/episodes/`。历史完整水印和旧短水印不再公开签发；收费内容重新排队生成新短片，免费旧任务取消。旧 OSS 文件、已批准发布快照、订单和 HLS 保留。
- 启用或启动市场时先协调旧任务，再启动原有市场 Worker。失败最多自动重试配置次数；终止任务带策略标识，重启不会重置重试上限。旧任务回填校验当前资产、版本和租约，不会覆盖新内容，也不会自动恢复作者主动下架。
- 已批准作品的预览修复可使用 `POST /api/marketplace/works/{id}/preview/retry` 或 `POST /api/marketplace/series/{id}/preview/retry`，请求体为当前 `version`。仅作者可操作，重复请求不重复排队，不修改已批准内容、价格、原片、上架选择或 HLS；收费上传/重试要求真实 OSS 可用。
- 媒体接口维持 `{url, expires_in}`，签名前校验公开状态、权属和用途，默认有效 300 秒。免费签原片，收费只签合格短试看。已有买家仍按购买时的 `publication_id` 和永久权益播放 HLS。
- 日志记录下载、源文件校验、截取、输出校验、上传与状态回写的阶段耗时。用户错误仅包含阶段提示，不回传 OSS 凭证或底层异常。
- 没有烧录水印并不提供绝对防复制能力；试看仍可能被保存或录屏。首次处理仍有 OSS 下载上传成本，短剧拼接和完整 HLS 封装也仍需 Worker。

当前已完成：用户端系列创建/编辑/导入/提交、系列和分集浏览，单视频三种收费类型，管理员系列审核、分成配置、订单/权益查询（支持购买用户和创作者筛选）、收益账本、人工打款和分类配置，市场 Worker 试看/HLS 任务，以及短时签名播放权限。当前仍需真实环境验收：共用 OSS 的分片上传、私有对象与分片签名、FFmpeg/HLS 播放、易支付回调和 App 播放端；本地未配置真实服务时这些接口只能验证错误码和权限边界。

核心接口：系列使用 /api/marketplace/series、/series/{id}/episodes、/series/{id}/episodes/import 和 /series/{id}/submit；平台内容使用 /platform/feed、/platform/episodes/{id}、/platform/works/{id} 及对应 /playback；订单使用 /content-orders、/entitlements 和 /payments/epay/notify。播放接口只返回短时签名清单或原片链接，详情接口不会泄露 OSS 密钥。当前不提供 Web 观众端支付/播放页面，App 应按接口接入。
## 当前招募规则：联系客服接单（2026-10-21）

招募只提供需求展示与客服撮合：需求方保存草稿 → 提交管理员审核 → 招募广场展示；创作者查看需求 → 登录 → 联系客服接单 → 客服线下协调预算、授权、合同与交付。接单咨询不需要上传视频、报价表单或版权材料，咨询不代表已接单或成交。

详情保留需求说明、预算、数量、交付要求、授权意向、截止时间及最多6张参考图；作者从“我的发布”进入管理。用户端取消“我的投稿”、视频投稿、审片和选稿入口。后台日常只保留招募审核，旧记录移到“运行维护 → 历史投稿记录”，不删除已有数据。

新投稿及选稿接口已停用：`POST /api/marketplace/recruits/{id}/submissions`、`POST /api/marketplace/submissions/{id}/selection` 对已登录调用返回410，`detail.code=MARKETPLACE_SUBMISSIONS_DISABLED`，不修改资产、不创建投稿和审片任务；接口文档不再展示这两个旧入口。详情的旧字段 `can_submit` 固定为false，`can_contact` 表示当前登录创作者可联系开放需求。旧记录读取、撤回和私密文件权限保留兼容，不恢复线上投稿流程。

客服沿用“数字资产平台运营 → 客服配置”中的真实二维码、微信及服务时间，弹窗提供招募编号、标题、预算、当前链接的一键复制。无客服配置返回503；关闭、到期、未审核或封禁需求不接受创作者新咨询。本文下方的历史投稿、审片、选稿说明均以本节为准。

只需重启后端并刷新前端页面，无数据库迁移或历史数据清理。不影响作品发布、作品试看和原项目业务。

## 历史作品试看规则（2026-10-21，已由上文新版策略替代）

本节替代下文历史版本中关于普通作品转码、免费价格、预览时长及双重审核的说明。市场 Worker 现随后端自动启停，异常退出自动恢复，不需另开终端。

- 发布方式可选择免费（价格为0）或付费。上传、保存草稿不创建水印任务。免费公开播放完整时长水印，不提供无水印原片，也不代表任意商用。
- 提交作品时一次校验版权信息：PrintFilm 仅关联已签署授权函；其他平台填写证书编号、上传截图/照片并确认版权声明；无材料直接联系客服线下协办，不在作品流程创建登记案件。
- 提交审核后进入 `processing`，Worker 生成保留原分辨率、原帧率的高保真烧录水印（H.264 CRF16，不保证逐像素无损；奇数尺寸仅补齐偶数）。免费和零元作品为完整时长；有标价的版权作品时长不超过 `min(15秒, 原片时长*30%)`，编码为封装取整预留少量余量。公众播放不回退无水印原片。
- 水印包含 PRINTFILM、作者名字和「侵权必究」，上下两处烧入画面。不会为普通作品额外生成完整审片或封面；封面由用户上传。
- 生成成功自动进入 `pending`；管理员查看原片、公众试看及版权材料，一次审核，作者再上架。失败最多自动尝试配置次数，终止后显示 `preview_failed`，作者可点击重试生成并提交。
- 新增独立表 `marketplace_work_previews`；启动 API/Worker 时通过现有独立 metadata 创建新表，不修改原业务表或现有列。按作品和原片去重，同片修改标题/价格金额复用试看；替换视频创建新任务。结果更新须符合当前作品版本、媒体、付费及提交状态。
- Worker 单进程串行执行，作品试看使用120秒租约、20秒心跳，进程重启可恢复。每次尝试使用独立 OSS 对象，过期任务不能覆盖新结果。不得启动多个 Worker 来追求并发；当前建议保持一个。
- 公开媒体接口对付费作品只签发独立试看对象，缺失或失败时拒绝播放，不回退原片和旧版 `Asset.preview_key`。免费转付费先撤下、生成试看并重新审核；已签发原片链接仍最多存活5分钟，已被保存的原片无法收回。
- 旧版已上架付费作品没有该试看记录时，从公开列表及公开播放中排除。作者需从“我的发布 → 查看与管理”重新提交，生成试看、审核通过后再上架；不自动处理历史文件、不替作者重新上架。
- 后台“运行维护 → 作品试看任务”查看任务；作品记录可分别打开原片与公众试看。任务数据不包含公开原片下载接口。

## 共用 OSS、独立目录与媒体进程

下游直接读取后台「系统设置 → 存储 OSS」的启用状态、Endpoint、Bucket 和凭证，与原业务共用 Bucket。固定使用 `marketplace/` 目录，原业务继续使用原 `OSS_FOLDER`（默认 `kepu/`），请勿将原业务目录设置为 `marketplace/`。无需配置 `MARKETPLACE_OSS_*`，旧的同名环境变量不再生效。所有原片、封面、水印预览、版权材料、参考图、客服二维码使用 OSS 对象标识。模块不创建 Bucket，不改 ACL、CORS、生命周期及上游配置。

客户端会只读检查 Bucket ACL 和 policy，公开 ACL 或匿名 Allow 策略将阻止市场文件使用。目录不是权限边界：共用 Bucket 仍须保持私有，原业务已通过对象 ACL 显式公开的文件继续遵循原上传逻辑；下游始终显式上传为 private，不调用原公开上传函数、不使用公开域名。不会自动改动现有云端权限，实际兼容性待真实 OSS 联调。RAM 权限需要包括共用 Bucket 的 GetBucketAcl/GetBucketPolicy，以及 `marketplace/*` 下文件读取、上传、multipart 初始化/分片/完成/取消权限。没有 Bucket policy 时允许 `NoSuchBucketPolicy`；元数据检查权限不足时失败关闭。部署方需配置文件保留、备份、日志及未完成 multipart 的兜底生命周期。

浏览器播放器通过已鉴权的接口取得短时 GET 链接，不接收 OSS 密钥。默认有效期300秒；下架、撤回后不再签发新链接，旧链接最长5分钟后过期。播放、Range 和二维码图片访问应在真实 Bucket 上验收。原片和证据仅作者或管理员可申请访问，需求方只能获得水印审片。

市场 Worker 已随后端自动启动，不需另开终端。仅在确需独立运行时使用兼容命令：

```powershell
cd C:\code\printfilm\backend
.\.venv\Scripts\python.exe -m app.marketplace.worker
```

Worker 随 API 自动启动和停止，由市场独立看门狗恢复，不接入原 TaskRun、AI 计费或原调度器。通过 PostgreSQL 事务级咨询锁保证多个后端进程或兼容命令之间总媒体并发为1。默认单并发，任务持久化、SKIP LOCKED领取、90秒租约和20秒心跳；最多自动尝试3次，失败可通过作者工作台重试。多进程使用同一租约规则，首版建议只部署一个 Worker。生产需用进程管理器托管并监控失败任务。

视频默认最大500MB、最长30分钟，支持MP4/MOV/WebM。8MB分片转发到OSS，会话24小时，重复同一分片和重复完成保持幂等。重新选择同一文件可以恢复已成功的分片，上传中可取消；取消未获云端确认时显示错误并保留恢复信息。完成后校验OSS真实大小，Worker校验文件内容、指纹和媒体信息。

FFmpeg 在系统临时目录的 `printfilm-marketplace-cache/job-*` 内处理付费试看和平台投放 HLS。版权咨询试看最多 15 秒且不超过原片 30%，保持源分辨率和帧率并烧录水印；平台投放播放版本保持源分辨率，优先无重编码分段。免费作品不生成试看或默认封面，封面由作者上传。临时文件只作缓存，上传到私有 OSS 成功后才标记就绪，任务结束和超时清理。

## 业务操作顺序

### 单视频与短剧

1. 作者上传单视频或创建短剧系列，保存草稿只保存资料，不要求授权材料，也不创建试看任务。
2. 单视频提交审核时选择免费、联系客服购买版权或平台投放收益；短剧逐集填写收费类型、价格和权属信息。平台投放还必须已有后台默认分成或单项分成。
3. PrintFilm 生成只关联当前有效授权函；其他平台填写证书编号、证书截图/照片并勾选版权纠纷声明；没有材料只能联系客服协办，不创建新登记案件。
4. 后端校验媒体、封面、权属和收费信息后，付费内容由同一个市场 Worker 生成试看；管理员在一个审核入口同时检查内容与版权，结果只有待审核、已通过或已驳回。
5. 审核通过且版本就绪后作者上架。修改视频、权属、收费类型或价格会创建新版本并重新审核；已购买旧版本继续使用旧播放资产。

单视频保留一条视频一张封面；短剧系列要求至少一集、集数连续且每集视频/封面/材料/试看就绪。分集可以手动上传，也可以明确选择本人漫剧项目中已生成的分集导入，导入复制并保存来源快照，不修改原漫剧。

### 权属与客服协办

作品和版权信息只提交一次、管理员只审核一次。不要向用户展示基础核验、完整核验、私密核验或自行办理登记案件。授权函或证书材料修改会使当前版本重新进入待审核；证书编号本身不代表平台保证无侵权。客服协办不自动通过，服务费或登记机构费用按线下通知处理。
### 招募与客服接单

需求保存草稿、提交审核，通过后公开；最多6张参考图。创作者浏览需求后先联系平台客服，由客服协调合作，不在线上传视频、报价或选稿。

联系客服时提供业务编号、标题、预算和页面链接；具体价格、版权约定、合同及交付在线下确认。未配置真实客服时明确提示不可用，关闭或到期后停止创作者新接单咨询。

历史投稿不删除，原私密权限继续生效；曾有投稿的旧需求继续锁定预算、数量、授权、规格、说明和截止条件，重大变更关闭后重新发布。新需求不创建投稿记录。

### 客服、投诉与原片交付

管理员上传真实二维码、等媒体处理后保存客服配置。没有真实配置时显示不可用，不使用社区微信代替。不创建订单、支付、在线买家下载或授权凭证；客服线下确认合同、收款、原片交付。咨询事件仅用于统计，不能视为扫码或成交证明。

举报需要说明和联系方式，可在页面附带本人证明文件。管理员查看证据后可限制作品、需求、权属或投稿，再记录处理结论并通知用户。举报不自动永久封号。投诉人联系方式、证据不公开。敏感材料的读取和审核保留访问记录。下游页面隐藏原站社区入群浮标，业务咨询只使用后台维护的专用客服。
