# 画布整理与左键平移验收

## 使用方式

- 点击底部工具栏“整理”，或按 Alt + Shift + F；工作区设置中的“整理画布”使用同一个入口。
- 连线相连的节点归纳为关联流程，零散节点按文本、图片、视频、音频、导演台等类型集中放置。保留已有用户分组及其内部层级，根据节点实际尺寸留出间距。
- 左右各一只小手交替搬动节点，显示当前节点和整理进度；点击“直接完成”或按 Esc 可以跳过动画。系统启用减少动态效果时直接完成布局。
- 一次整理对应一条撤销记录。完整布局一次提交，动画只是展示，不逐帧写入持久化数据；节点内容、素材、任务和连线端口均保留。重复整理不会不断嵌套自动分组。
- 箭头选择工具下，左键拖动画布空白处或分组留白可以平移；拖内容节点仍移动节点；Shift + 左键拖动用于框选；拖分组标题移动整个分组。

| 间距 | 整理完成后的 84 个内容节点，浏览器几何检查无重叠 |
| 直接完成 / Esc | 两种方式均结束动画并保留完整布局，没有残留活动节点标记 |
| 撤销 | 一次撤销后，全部节点 ID 和位置恢复到本次整理前快照 |
| 重做 | 整理分组和布局恢复；自动化组件测试同时验证一次撤销移除整批新建分组 |
| 保存 / 刷新 | 显式保存显示“已保存”；刷新后 98 个对象、14 个分组及类别名称保留 |

| 分组留白平移 | 命中画布层，视口移动 (90, 40)，分组及所有内容节点坐标均不变 |
