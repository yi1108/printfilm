## 使用方式

- 项目是协作单位。打开项目画布，点击右上角「分享」，在「项目团队与分享」中管理成员与邀请。
- 项目所有者可创建 1 / 7 / 30 天有效的邀请链接、撤销链接、移除协作成员。每个项目最多同时保留 10 条有效链接。
- 受邀者登录后点击接受邀请，仅加入该项目；在自由画布列表的「我参与的项目」中重新打开。
- 项目成员可编辑画布、使用素材和查看生成结果；邀请与成员管理仅限所有者。项目协作不授予其他项目、原团队管理、漫剧分集编辑和他人钱包权限。
- 撤销邀请阻止后续加入，已加入成员需单独移除；如需防止被移除者通过原链接再次加入，应同时撤销有效邀请。
- 无本地未保存修改时，画布每 2 秒同步成员修改。并发保存使用文档版本校验；冲突保留本地内容并提示导出、刷新，不会静默覆盖。

## 计费与兼容

- 新的画布图片、视频、音频、AI 写作、Agent 及批量工作流，均使用发起人的个人钱包。
- 发起人由后端登录身份确定。任务保存 `requested_by` 和 `billing_payer_user_id`，不接受客户端指定付款人。
- 余额检查、排队承诺、冻结、结算和失败退款沿用个人计费生命周期。其他成员不能取消由他人发起的生成。
- 新的项目成员关系与原组织团队独立；原组织团队成员不会自动取得该项目团队权限。项目创建者为项目所有者，可重新通过项目链接邀请成员。
- 不迁移历史账单、不修改原组织团队成员和钱包。已有任务按其保存的计费归属结算。

## 数据库

新增 `printfilm_studio_canvas_members` 与 `printfilm_studio_canvas_invitations`，均以 `project_id` 关联项目。邀请数据库仅保存 SHA-256 摘要，原始链接仅创建时返回。链接凭证放在 URL fragment，接受邀请通过 POST 提交；登录跳转仅在当前标签页临时保存待接受凭证，30 分钟后失效，加入后删除。

自动 bootstrap 开启时由 Studio schema patch 创建。关闭时在 backend 目录执行：

```powershell
.venv/Scripts/python.exe scripts/migrate_project_canvas_sharing.py
.venv/Scripts/python.exe scripts/migrate_project_canvas_sharing.py --check
```

该迁移只增建两张表，不回填或修改业务数据。当前本地配置已执行迁移并重启后端。
