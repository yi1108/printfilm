## 修复与交互

1. 从已有素材启动参考生成，先创建独立输出草稿及源→目标连线，再打开新节点的参数面板。创建和连线共用一次撤销。修复工具栏点击冒泡重新选中源节点、导致新面板消失的问题。
2. 图片输入拒绝音视频，配音输入只接受文本，分类框不参与生成连线。React Flow 拖线有效性检查和引用添加共用校验；旧的不兼容引用保留但禁用生成并提示移除。
3. 引用选择器过滤不支持的类型；“从素材库选择”打开带类型过滤的分页库，选择后创建输入节点并连线，一次撤销恢复。
4. 连线改为更清晰的曲线，22px 命中区域；仅选中连线显示流动虚线，支持减少动态效果偏好。
5. 素材库每页 24 项，固定 156px 卡片行高，筛选重置页码，翻页回到列表顶部；顶部避开工作区导航。
6. Agent 引用面板增加当前画布/项目素材/我的素材来源、搜索、缩略图与类型、分页。分类框不再混入可引用内容列表。
7. 添加→分类框：有选择则包裹所选内容，无选择创建空框；支持将独立节点拖入手动框，双击框标题只编辑名称。
8. 提交、排队、生成及蒙版合成状态以整张节点卡片显示。提交状态按节点 ID 管理，其余节点不显示忙碌状态；完成后显示结果。
9. 生成提交等待正在进行的自动保存，避免将“保存尚未完成”误判为冲突。
