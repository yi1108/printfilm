## 12. 建议下一迭代切片（可直接开工）

按「投入小、体感大」排序：

### Sprint A — 体验与稳定性（P0）

1. 部署前端：帮助侧栏 + `effectiveStatus` 状态文案  
2. 流水线：项目级互斥锁 / 队列去重，避免同项目并行双任务  
3. 续跑失败时保留素材，明确错误提示（勿清空分镜）

### Sprint B — 创作输入与风格（P1）

1. **C-01** 文章链接抓取 → `source_text`  
2. **C-02** 文档上传解析  
3. **S-04 / S-05** BGM + 字幕样式最小集接入合成  

### Sprint C — 编辑器与资产（P1）

1. **E-06** 本地上传替换镜头图  
2. **E-04 / E-05** 增删镜头与调序  
3. **E-03 / Y-04** 编辑器导出与历史页复制分享链接  

### Sprint D — 商业化（P1–P2）

1. **P-01～P-03** 定价与额度  
2. **Y-02** 历史页额度条接真实数据
