# 导演规划与依赖运行（2026-11-06）

已实现：

- 空白图片、视频节点单击直接打开原有生成输入框；移除中间的顶部生成按钮。已有媒体、运行中节点、多选和平移保留各自行为。
- 导演规划保存 `writingPrompt` 写作要求，写作节点的 `text` 初始为空；角色／场景图片依赖对应写作节点，分镜写作节点依赖所需参考图，视频依赖最终提示词及参考图。
- 右键／节点菜单“运行到这里”和方案“应用并运行”共用依赖调度。沿入边找上游，已有有效结果复用；同层并行，后续层等待真实结果，失败停止后续层。
- 确认框列出文本／图片／视频任务和实际接口报价。文字 Agent 接口目前没有本站钱包扣费，显示 ¥0，不使用参考截图中的虚构积分。

- 逐节点保存结果；检查写作要求、参考输入和连线变化。可停止后续运行，已经提交的媒体任务保持可追踪。离开页面停止后续调度，再次运行可复用已保存结果。
- 旧正文和已生成媒体保持不变；新规划使用延迟写作。修复旧分镜关系时补齐参考图到写作节点的依赖边。
