## 接口与数据

- 新增 `POST /api/printfilm-studio/agent/sessions/{session_id}/messages/{message_id}/actions`，动作 `branch`、`edit_branch`、`truncate`。
- 请求携带 `expected_sequence` 与 `expected_last_message_id`。二者一起防止删除后重新补齐相同消息数时绕过并发检查。
- 所有操作首先检查会话归属和项目/团队空间；事务内与 Agent 开始执行竞争同一会话锁，执行中禁止改写历史。
- 分支复制到指定消息的对话与工具轨迹，不复制任务、不重新执行工具、不改变画布。
- 工具事件增加 `call_id` 和输入信息；历史恢复兼容此前未带调用编号的事件。
- 不新增表，不迁移、清空或覆盖用户已有画布。
