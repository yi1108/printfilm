# Printfilm Studio 顶部工作区更新

日期：2026-11-06。按用户截图实现；用户自行进行界面验收，本次未执行浏览器验收。

## 已实现

- 顶部浅色工具栏：项目与画布入口、真实保存状态、画布/故事板切换、默认模型、搜索、任务、导出、生成历史、更多菜单、分享、余额、账号。
- 故事板：音频/文本、图片、视频三列，独立滚动、计数、添加、展开、编辑入口及媒体预览。
- 默认模型：读取实际模型目录；图片、视频、文本分别保存浏览器偏好并用于新建节点。已有节点保留自己的模型；无指定模型时跟随平台默认。
- 生成历史：提示词搜索、类型/状态过滤、分页、日期分组、图片/视频/音频预览、多选加入当前画布。后端搜索保留用户范围，百分号与下划线按普通字符匹配。
- 更多菜单：复用配方库；画布设置、项目名称/画布名称、新建/切换项目、浏览器历史快照、JSON 导入导出、视频与音频创建入口、说明与主题切换。
- 分享：复制实际项目链接；展示个人所有者或团队成员，跳转现有团队邀请/权限管理。
- 余额：实际余额、本月消费/调用、冻结金额、消费明细、付费订单入账、订单与充值入口。
- 图片草稿：显示与编辑统一读取 prompt，原始 text 保留；空图片节点自动高度限制为 280，已生成媒体与用户手动调整的尺寸保留。

## 实际能力边界

- 分享链接不绕过权限；本次没有新增匿名邀请链接。个人项目需要先转入团队才能协作。
- 当前平台没有兑换码接口，入口明确显示“暂未开放”。
- 历史版本是本浏览器、当前账号和项目隔离的保存快照，最多 12 个，每分钟最多记录一次；不是服务端版本库。
- 画布包为 JSON 文档，媒体仍通过原地址引用，不是包含离线媒体文件的 ZIP。
- 画布管理沿用当前“一项目一画布”结构。
- 入账记录来自已支付订单；消费指标按后端提供的本月统计展示，不冒充累计或今日统计。
