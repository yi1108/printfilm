# 节点参数与图片编辑调整（2026-11-05）

## 参数与创作入口

- 图片、视频生成参数使用自定义弹出菜单，支持键盘选择和 Escape 关闭。
- 视频模式：文生视频、图生视频、首尾帧、全能参考；参数按后台模型能力提供，提交前校验参考类型和数量。
- 视频费用沿用现有后台配置与报价，展示每秒费用和预计总额；目录未提供单价时，以报价除以时长展示近似单价，不新增折扣或积分计费。
- 手动新建的空视频卡提供参考图、首尾帧、故事脚本三个入口，可选择已有图片或新建输入节点并连线。
- 文本支持自己写、AI 写、格式工具、写作类型与技能；导演入口带上选中脚本和规划指令。

## 最新反馈调整

- 排队/生成内容不再使用 200px 最小高度；加载区限制在节点内部，生成期间隐藏视频说明，避免撑出边框。
- 图片加载后按真实宽高调整节点尺寸；用户调节宽度时保留图片比例，多图缩略条单独计入高度。
- 编辑图片、裁剪打开同一编辑弹窗，分为局部编辑与裁剪两个页签。
- 局部编辑有画笔、笔刷大小、橡皮、撤销、全选、清除选区与修改要求。提交时建立新的图片结果节点，再沿用现有局部重绘流程；原图不被修改。
- 裁剪支持自由、原图、1:1、16:9、9:16、4:3、3:4，支持边角拖动、移动选区、键盘微调与重置，展示实际输出尺寸。裁剪结果上传为新素材、新节点，并与原图连线。
- 移除图片工具条的替换图片入口；局部重绘并入编辑图片。
- 从图片创建图生视频或参考生成视频时，结果卡片为空白，不重复展示尝试入口；提示词不再自动填充模板。
- 图片卡片和生成输入框内的 @ 引用使用包含缩略图的原子标签。保存稳定的素材/节点 ID，发送给生成接口前转成人类可读标签，参考文件仍通过已有连线收集。
